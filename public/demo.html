What it does

Six engines, one workflow.

⚡

Intent Detection

Classifies prompts into coding, writing, research, analysis, planning, creative, conversation.

🔎

Gap Analysis

Rule-based heuristics + LLM reasoning find the 3–6 missing details that matter most.

❓

Clarification Q&A

Generates concise, friendly questions ranked by impact. Captures answers in a session.

🧠

Prompt Reconstruction

Rebuilds a structured prompt: CONTEXT, OBJECTIVE, CONSTRAINTS, FORMAT, SUCCESS CRITERIA.

🎯

Model Formatter

Adapts output to ChatGPT (numbered steps), Claude (XML tags), Copilot (code-comment intent).

🧩

Browser Extension

Manifest V3. Injects an Enhance button on ChatGPT, Claude, Copilot, Gemini.

  Deploy
  
From repo to live URL in 4 steps.

  

    

      
Supabase

      
Create a free project, run 0001_init.sql, copy URL + keys.

    

    

      
Ollama

      
ollama pull llama3 mistral phi3 & ollama serve. Free Cloudflare tunnel exposes it.

    

    

      
Vercel

      
Import the GitHub repo, paste 9 env vars, click Deploy.

    

    

      
Extension

      
Load extension/ unpacked in Chrome. Set API URL + key in Options.
