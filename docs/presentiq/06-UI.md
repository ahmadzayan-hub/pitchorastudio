# PresentIQ — UI / Wireframe Structure

Premium, clean, corporate. Tailwind + a small set of shadcn-style primitives in `src/components/presentiq/ui/`.

## 1. Page Map

```
/                                    Landing (marketing)
/login                                Auth
/presentiq/dashboard                  Org dashboard (recent projects, KPIs)
/presentiq/projects                   Project list
/presentiq/projects/new               Wizard (10 steps)
/presentiq/projects/:id               Project overview / agent progress
/presentiq/projects/:id/editor        Slide editor + storyboard
/presentiq/projects/:id/review        Approval & comments
/presentiq/projects/:id/export        Export center (PPTX / PDF / notes / sources)
/presentiq/brand-kits                 Brand Kit list
/presentiq/brand-kits/:id             Brand Kit editor (logos, fonts, colors, tokens)
/presentiq/admin                      Admin (audit logs, users, plan)
/presentiq/billing                    Billing (Stripe portal)
```

## 2. Wizard Steps

Stateful 10-step wizard, persisted to `pq_presentation_projects` after step 4.

1. Mode picker — 12 modes (cards with icons + descriptions).
2. Brief — title, topic, audience, objective, decision, language mode, duration, slide count, confidentiality.
3. Sources — drag-drop multi-file upload.
4. Brand Kit — pick org default / upload / UAE Pine preset / Government preset / Consulting preset.
5. Blueprint — agent progress + blueprint review (approve or revise).
6. Generate — agent timeline (Intake → Evidence → Brand → Strategy → Storytelling → Architect → Copywriter → Visual → Data → RTL → Translation → Renderer → Animation → QA → Security → Export).
7. Quality Review — score panel + recommendations.
8. Edit — slide editor.
9. Approve — lock approved slides.
10. Export — PPTX, PDF, speaker notes, source sheet.

## 3. Slide Editor

Three-pane layout:

- Left: storyboard thumbnails (drag to reorder, lock icon).
- Centre: live slide preview + inline edit.
- Right: actions panel — `Regenerate`, `Simplify`, `Make Executive`, `Make Visual`, `Translate to Arabic`, `Bilingual`, `Add Speaker Notes`, `Change Layout`, `Change Chart`, `Lock`, `Approve`.

## 4. Quality Score Panel

Donut: **Boardroom Readiness** in centre. 9 satellite bars: Brand, Evidence, RTL, Simplicity, Visual, Executive Clarity, Accessibility, Hallucination Risk, Template Compliance.

## 5. Agent Progress Screen

Vertical timeline with live status:

- Reading files…
- Extracting evidence…
- Building story…
- Designing slides…
- Applying brand rules…
- Checking Arabic RTL…
- Rendering PPTX…
- Running QA…

Driven by SSE from `/api/presentiq/projects/:id/blueprint` and `/slides`.

## 6. RTL Support in UI

- `dir="rtl"` is set on Arabic content blocks.
- Mirroring honours: timeline progress direction, navigation chevrons, breadcrumbs.
- Layout uses logical CSS properties (`ms-*`, `me-*`) not directional ones.

## 7. Visual Language

- **Type**: Inter (English), Tajawal (Arabic) — fallbacks Noto Kufi Arabic, Alexandria.
- **Color**: a neutral system palette (zinc 50→950) + accent maps onto the active brand kit.
- **Density**: white space first; one idea per surface.
- **Motion**: Framer Motion, restrained — no decorative animation.

## 8. Empty / Error States

Every list view has a real empty state with the next-best action; every error renders a humane message + retry, never a stack trace.
